# GetCookie - 京东 Cookie 助手安卓版 (v2.2.4)

一款专为京东用户设计的 Cookie 获取、资产查询与一键云端同步工具。

## 🚀 性能革命：极速响应

*   **毫秒级查询**：引入“关键词过滤请求”技术，从数以百计的任务中秒级定位资产脚本，数据传输量降低 **99%**。
*   **网络库重构**：
    *   **连接池复用**：全应用共享 TCP 连接，彻底消除频繁的 HTTPS 握手开销。
    *   **SSL 缓存**：全局缓存 SSL 上下文，拒绝重复计算。
    *   **Gzip 压缩**：强制开启数据传输压缩，在移动网络下体验更丝滑。
*   **性能监控**：内置 Logcat 耗时统计，每一跳网络请求透明可见。

## ✨ 视觉进化：精致 UI 体验

*   **沉浸式登录**：重构启动加载页，采用深蓝品牌色与圆角卡片图标设计，科技感拉满。
*   **全应用品牌色**：由内而外统一采用 Indigo (#283593) 配色，视觉高度和谐。
*   **卡片式交互**：
    *   **现代化加载框**：告别陈旧的系统加载圆圈，采用清爽的圆角浮窗。
    *   **美化结果页**：资产统计结果以精致的定制化卡片呈现，支持平滑滚动与等宽字体阅读。
*   **圆角组件**：操作按钮全面升级为 Material Design 3 风格，触感与视觉双重提升。

## 🛠️ 核心功能

*   **资产一键统计**：登录后点击“资产查询”，自动关联当前账号并提取京豆、红包、过期提醒等核心数据。
*   **智能推送与备注**：一键同步 CK 至青龙，自动添加 `app:` 前缀及 `pt_pin` 备注，自动切换为“启用”状态。
*   **极致稳定性**：深度优化 WebView 状态恢复，切后台或进程重启后无需重新登录。
*   **安装无忧**：针对国产手机深度优化 Gradle 配置，解决 Debug 包安装异常 (-15) 顽疾。

## 快速开始

1.  **环境**：Android 7.0 (API 24)+。
2.  **配置**：在 `LoginActivity` 或配置文件中设置青龙面板地址、ClientID 和 ClientSecret。
3.  **操作**：登录京东 -> 点击“获取CK”或“资产查询”。
