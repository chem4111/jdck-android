# GetCookie - 京东 Cookie 助手安卓版

一款专为京东用户设计的 Cookie 获取与自动推送工具，支持一键同步至青龙面板。

## 核心优化与功能

*   **精简 UI**：移除了冗余的短信监听和手机号管理，界面仅保留“获取CK”与“重置”功能，极致纯净。
*   **智能推送**：
    *   点击获取时，自动从 Cookie 中提取 `pt_pin`。
    *   自动匹配青龙面板中已存在的 `JD_COOKIE` 环境变量进行更新。
    *   自动添加/更新备注为 `app:pt_pin`，便于区分推送来源。
    *   推送成功后自动调用接口将其设置为“启用”状态。
*   **稳定性增强**：
    *   优化了 WebView 状态保持机制，切后台、退回桌面或系统回收后，登录态依然有效。
    *   采用动态 URL 构造，提高登录页的加载成功率。
*   **全新图标**：采用矢量化 `chem` 极简风格图标，在任何分辨率下均保持清晰。
*   **兼容性修复**：针对 vivo/OPPO/一加等机型常见的安装异常 (-15) 进行了底层配置优化。

## 快速开始

1.  **环境要求**：Android 7.0 (API 24) 及以上。
2.  **配置青龙**：确保在 `LoginActivity` 或相关配置文件中填写了正确的青龙面板地址、ClientID 和 ClientSecret。
3.  **获取 CK**：打开应用，在内置页面登录京东，点击“获取CK”即可完成复制与推送。
4.  **重置**：需要更换账号或重新登录时，点击“重置”即可清空所有缓存。

## 注意事项

*   **安装失败**：如果遇到安装异常，请务必先**彻底卸载**手机上的旧版本后再试。
*   **网络提示**：已过滤非主页面的网络报错弹窗，专注于登录体验。
